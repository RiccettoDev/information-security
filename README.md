# information-security

• Confidencialidade: Garante que a informação seja acessada apenas por pessoas ou sistemas com permissão, mantendo o sigilo dos dados.
• Integridade: Assegura que os dados estejam corretos, precisos e livres de alterações ou corrupções não autorizadas.
• Disponibilidade: Confirma que os sistemas e as informações fiquem acessíveis aos usuários autorizados sempre que necessário.
• Autenticidade: Confirma a identidade de quem está acessando o sistema ou enviando a informação, garantindo que a origem é genuína.
• Legalidade (ou Irretratabilidade): Assegura que as ações realizadas não possam ser negadas posteriormente, cumprindo as normas e leis vigentes (como a LGPD).
